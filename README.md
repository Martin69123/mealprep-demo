# Mealprep & træning — test demo

A test prototype of a meal-prep and training app. It runs entirely in the browser and stores its
data only on the device it is opened on. It is not a finished product and gives no health advice.

- Open the app: `web/` on this site's GitHub Pages address.
- Nutrition data: Frida, version 5.5, National Food Institute, Technical University of Denmark
  (doi:10.11583/DTU.29500682), CC BY 4.0. The data is a rounded subset. DTU does not endorse this app.
